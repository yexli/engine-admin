# 天穹纪元 2.0

**世界书驱动的单机 AI 文字角色扮演游戏。**

恒定归引擎，讲述归 AI —— 世界规则、数值结算与状态演化全部由本地确定性引擎裁定，
语言模型只负责把结果讲成人话。不配任何模型也能完整通关。

## 这是什么

你在圣辉城的中央广场醒来，身上有一把剑、一点钱和一个名字。接下来做什么由你说——
「去东市打听消息」「把这块矿石卖给铁匠」「夜里翻墙进神殿后院」「跟她谈谈三天前那件事」，
自由文本会被解析成意图与参数包，再由引擎判定成败、结算后果、改写世界。

世界不会等你。NPC 按自己的日程出没于酒馆、集市与神殿；势力之间有自己的外交矩阵；
你在商店里大额扫货会推高这类商品的价格；你做过的事会变成**别人的记忆**，
再沿着关系网传出去——传到你从未见过的人耳朵里，变成走样的传闻。

引擎与模型的边界是硬边界：**AI 不能改写世界状态**。模型提出判断与文本（这段叙事怎么写、
这个 NPC 会不会答应你的请求），由 core 的白名单校验后落地。因此：

- 判定可复现——同一存档 + 同一随机种子得到同一结果；
- 断网可玩——未配置模型时自动降级为规则模拟，功能不缺失，只是文字不再自由生成；
- 存档可信——导入的存档要过结构校验闸，结构错乱的档不会进入运行时。

## 核心特性

- **世界书驱动的内容层**：种族、职业、技能、物品、魔物、势力、地点、事件、地下城、
  配方、词缀、头衔、神祇全部以 JSON 世界书为单一内容权威，代码只读数据、不写死数值。
- **有记忆的 NPC**：记忆带置信度、来源链与可见性，会衰减、会被回忆强化、会被压缩成摘要。
  NPC 依据**自己记得的**而不是真相行动，因此误会与谣言是系统自然产物。
- **因果可追溯的事件系统**：事件由引擎按条件触发，后果沿因果链扩散，
  世界史时间线记录「为什么发生了这件事」。
- **六维势力关系**：总体态度 + 信任 / 敌意 / 通商 / 军事 / 信仰 / 情报。
  它们直接改写商店价格、神殿服务、城卫盘查概率与审判结果。
- **确定性规则层**：骰子、检定、战斗、经济、法律全部纯函数化，可回放、可测试。
- **AI 是可选加速器而非依赖**：四通道接入真实模型（意图解析 / 场景叙事 / NPC 权衡 / 自由对话），
  失败自动回退规则模拟，不阻塞游戏。
- **跨端运行**：浏览器直接玩；桌面用 Tauri 打包成原生应用，
  浏览器端用 localStorage、桌面端用 SQLite，存档格式对两端一致。

## 快速开始

### 环境要求

- **Node.js** `^20.19.0 || >=22.12.0`（Vite 8 的要求）
- 桌面版另需 **Rust 工具链**与 WebView2（Windows 10/11 自带）

### 安装与运行

```bash
npm install
npm run dev          # http://127.0.0.1:5273
```

打开后按提示创建角色即可开玩。移动端优先的界面，用浏览器的设备模拟（约 430px 宽）观感最佳。

> 仓库自带 `.npmrc`，把依赖缓存固定到工程同级目录；把它克隆到别处时可按需改回 npm 默认缓存路径。

### 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发服务器（5273） |
| `npm run build` | 类型检查 + 产出 `dist/` 静态站点 |
| `npm run preview` | 预览构建产物 |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint（含分层依赖守卫） |
| `npm test` | 全量确定性单测 |
| `npm run test:watch` | 监听模式 |
| `npm run format` | Prettier 格式化 `src/` |

## 桌面版

```bash
npm run tauri dev      # 桌面窗口（首次编译需拉取 Rust crates，较久）
```

## 接入语言模型

默认关闭，游戏用规则模拟推进。想获得自由文本叙事时，在游戏内
**系统 → AI 网关**填写：

| 项 | 说明 |
|---|---|
| Base URL | 任意 OpenAI 兼容端点，默认 `https://api.deepseek.com/v1` |
| 模型名 | 默认 `deepseek-chat` |
| API Key | 只存本机 localStorage，不进仓库、不外发 |

保存后可点连通性测试。生效后五个通道启用：自由文本意图解析（含攀谈/赠礼/请求等社交意图）、
场景叙事（带 ✦ AI 角标）、NPC 请求权衡（带 ·LLM 标注）、聊天窗口自由对话、叙事编织
（规则原文 → 小说正文）。任一通道失败自动回退规则模拟。

### 思考等级与流式输出

同一件事在三家端点上有三套参数名，面板把差异收走了——你选「想多深」，字段由它翻译：

| 端点 | 思考开关 | 档位 |
|---|---|---|
| Gemini（OpenAI 兼容层） | ——（无开关字段） | reasoning_effort: low / medium / high |
| DeepSeek | thinking: type = enabled / disabled | reasoning_effort（模型支持时） |
| GLM（智谱） | thinking: type = enabled / disabled | ——（无档位字段） |

- **思考等级**：默认 / 关闭 / 低 / 中 / 高。选「默认」时**一个思考字段都不发**，
  请求体与没有这个功能时逐字节相同；「关闭」只关得掉开关式的端点（DeepSeek / GLM），
  Gemini 的档位式没有「关」这一档，于是对它等于什么都不发——宁可退回端点默认，
  也不塞一个它不认识的取值换 400。
- **思考参数**：自动（按端点识别该发哪个字段）/ 仅档位 / 仅开关。自建代理认不出时，「自动」
  会把两种字段都发出去；真遇到对未知字段严格的端点，再手动切窄。
- **流式输出**：开着时编织、章级摘要、场景叙事与对话走 SSE，正文边生成边上屏（思维链不会
  混进正文，只在运行日志里记字数）。端点不认 stream（400 等）时自动回退整包重发一次——
  开不开都拿到同一份文本，差别只是「看见第一句话」要等多久。

两项都只影响「怎么问、怎么收」，不改变任何世界状态：文本仍旧经各通道解析后由 core 落地。

**机械短通道与思考模型**：意图解析、请求权衡、台词、开场白四个 JSON 通道一律**强制尝试关思考**
（这类机械映射任务思维链没有收益，只会从同一个 max_tokens 里挤掉正文）。关得掉的端点省时省钱；
关不掉的（Gemini 档位式、忽略 disabled 字段的部署、思维链内联进正文的 qwen/ollama 类）也有兜底——
预算给足（意图 640、解析失败再翻倍重试一次，权衡/台词 400，开场白 280）、内联 `<think>` 块自动剥离，
仍失败才降级规则模拟。你的全局思考档位始终作用于叙事与编织等长文通道。

## 技术架构

### 分层

```
types ← data ← [ world | events | actions | dice | validation | plugins | execution | systems | memory ]
              ← ai / repo ← store ← ui
```

依赖方向由 ESLint 的 `no-restricted-imports` 强制：引擎层不得依赖 React / Zustand / UI，
内容权威层（`types` / `data`）零依赖。表现层只从 `world/` 的门面进入引擎。

### 状态写入

世界状态有**唯一写入实现点**（`world/WorldMutate.ts`）。系统模块只做「调原语 + 自己的副作用」，
绕过该层直接改状态的写法会被 lint 守卫（`no-restricted-syntax`）拦下。

### 事件与 AI

`events/` 下有两条总线：`bus` 只承载 UI 信号，`worldBus` 承载世界事实，
带优先级分级、单 tick 配额与死信留痕。AI 层通过 `AiPort` 端口注册，
只能读世界书与只读快照，产出的后果计划要过多道校验闸才会执行。

### 存档契约

`validate(state)` 拒绝结构错乱（类型 / 取值域 / 引用 / 脏键），`hydrate(state)` 负责字段缺失补齐。
两者互补：任何一侧放宽都要同步另一侧。所以旧存档始终可读。

## 项目结构

```
src/
├── types/       领域类型 + Core→UI 表现契约（零依赖）
├── data/        世界书 JSON 与类型化加载器 WB
├── world/       世界基础设施：State / Clock / Runtime / API / Mutate
├── events/      双事件总线、事件模式、事件存储与处理
├── actions/     自由行动解析与执行
├── dice/        骰子引擎与检定驱动
├── validation/  存档校验、计划形状与权限校验
├── execution/   后果计划契约与执行器
├── plugins/     插件接口、注册表、能力登记与装配
├── systems/     23 个游戏系统（角色 / NPC / 战斗 / 对话 / 任务 / 库存 / 经济 / 势力 /
│                关系 / 声望 / 法律 / 宗教 / 学院 / 地下城 / 旅行 / 星枢 / 图鉴 / 命名 /
│                冒险经济 / 通讯网 / 文化习俗 / 时空秘境 / 仪式）
├── memory/      记忆引擎：存储 / 生命周期 / 检索 / 信念 / 传播 / 向量缓存
├── ai/          网关与适配器、规则模拟、上下文构建、后果推演
├── repo/        持久化适配（localStorage / 内存 / SQLite）
├── store/       Zustand：UI 信号、浮层、toast（非事实来源）
├── ui/          React 组件与面板
└── tests/       架构守卫 + 逐系统回归
docs/            架构、玩法、约束与交付文档
scripts/         数据生成、基准、真机验证与截图脚本
public/assets/   插画位：放入 loc-/npc-/mob-{id}.webp 即生效，缺图回退符印
```

### 字体

正文宋体为自带资产：`@fontsource/noto-serif-sc`（思源宋体，SIL OFL 免费商用），
在 `main.tsx` 引入 400/600 两个字重，101 个 `unicode-range` 分片按需加载。
文档内 `@font-face` 优先于本机同名安装字体——玩家机器装没装思源宋都不影响渲染，
fallback 栈（Source Han Serif → 华文中宋 → 宋体）仅在资产加载失败时兜底。
CJK 无真斜体，全站不使用合成斜体（`rich()` 同时拒绝 AI 自带的
font-family/font-style/letter-spacing，强调只许字重与颜色）。

## 开发

### 门禁

改动合并前必须四项全过（**四项都要，不要挑着跑**）：

```bash
npm run typecheck   # 0 错
npm run lint        # 0 错（含分层与写入路径守卫）
npm test            # 全绿
npm run build       # 产出 dist/
```

### 测试

约 1500 条确定性单测（100 个文件），覆盖每个系统、架构守卫（依赖方向 / 写入路径 / 感知链路）与数值红队。
所有随机走统一种子源，测试可复现、可并发。

```bash
npm test                                  # 全量
npx vitest run src/tests/cardD1.test.ts   # 单个文件
```

### 脚本

```bash
node scripts/bench-shards.mjs           # 存档分片基准（体积 / 落盘量对比）
node scripts/verify-shards.mjs <url>    # 浏览器端存档真机验证（需 dev 常驻）
node scripts/assets-probe.mjs          # 素材缺口清单
node scripts/gen-dungeon.mjs           # 重生成地下城数据（确定性，勿手改产物）
node scripts/audit-direct-calls.mjs    # 跨模块直调审计
```

> 改代码前请先读 [`docs/技术架构与开发约束.md`](docs/技术架构与开发约束.md)：
> 分层方向、写入唯一入口、存档契约与既有踩坑都记在里面。

## 存档

- 浏览器：`localStorage`；桌面：SQLite（`saves` 表）
- 采用**分片存储**：主档（玩家 / 经济 / 日志 / 进程）与三张随规模增长的表
  （`npcs` / `记忆+信念` / `感知+案件`）分开保存，只写内容变化过的分片
- 整档与分片两种格式都能读；四片不齐时回落到上一份完整档，不会交出半成品
- 系统面板可导出 / 导入存档 JSON
