# 自由输入主通道 · 交付说明（2026-09-29）

> 用户方向两次裁定，本文记录最终形态与边界，供后续迭代对齐。

## 最终方向

1. **自由输入升格为社交主通道**：攀谈 / 打听 / 赠礼 / 请求四类社交意图直接吃自然语言，
   NPC 台词落进见闻录、由编织织成小说正文——「每一步都像在写小说」延伸到「每一句话都在小说里」。
2. **单独与 NPC 对话的功能保留**（用户 2026-09-29 裁决，推翻了「浮层瘦身」的初步规划）：
   对话浮层（剧情选项 + 深谈页 + 聊天窗）原样保留，仍是任务接取/复命、商店、赠礼赔罪、
   深度对话的专属界面。弱化的是「唯一性」，不是存在性。

## 双通道同源（关键架构事实）

两条入口，**一套管线**，会话史同池：

```
自由输入（Composer）                    对话浮层（npcTalk → 深谈页/聊天窗）
  「跟米露聊聊钟塔」                        输入行 / 话题 chips
       │ chatViaFree                            │ sendChat
       └────────────┬───────────────────────────┘
                    ▼
   Chat.sendChatTo：在场/敌意门禁 → 话题卡三层（matchTopic/topicDepth）
     → chatAsync（人设+记忆+近 6 轮 history）→ applyChat 结算
     （好感 clamp+日封顶、记忆验证闸、传闻扩散、每 3 轮推进、深水区代价）
                    │
        台词去向（唯一差异）：自由通道写见闻录（quoteSay 挂说话人），
        浮层通道回流深谈页/聊天窗气泡
```

因为同池，**在输入框说过的话，开浮层接着聊接得上；深谈页聊过的，输入框「再问问他」也接得上**。

## NPC 记得你（三层记忆）

1. **窗口史**：`s.chats` 每 NPC 20 轮入档，`buildCtx` 取近 6 轮进 prompt（G8 唯一组装点）。
2. **长期记忆**：AI 回包的 `mem` 过验证闸（memoryEngine.propose）进记忆库，按相关度检索；
   人物志「记得」一栏玩家可读。
3. **开场白接旧话头**（本次新增）：`GreetCtx.lastChat` 带上次对话的尾巴——
   开场白可以「你上次说到弟弟的病……」，比「你好」更像认识你的人。
