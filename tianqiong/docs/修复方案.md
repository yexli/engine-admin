### F-12 · core 写路径普遍缺 sync，UI 停在旧状态（P1，本批地基）

**位置**：`src/core/engine.ts:95-153`；`src/core/dialogue.ts` 多个 case；`src/core/actions.ts:165-305`

**机制**：`App.tsx:15` 订阅 `rev` 驱动全树重渲染，而 `QuestPanel` 与 `TopBar` 不自订阅、只靠 `rev`。实测这些分支改状态后既不落盘也不发 `changed`：`dialogue` 的 `q_debt`/`q_guild`/`q_theft_give`/`q_holy_give`/`q_letter_give`/`q_shard_give`/`q_caravan_give`（`giveQuest` 一律无同步）、`info_buy`(-200 铜)、`info_ash`(-150 铜)、`msg`(-50 铜)、`song`/`lore_t`/`lore_s`/`law` 的 `advance`；`actions.gather/exploreWild/exploreCave/restAt('wild')` 进战斗前也无 `sync()`。可复现：与莉塔接下债务委托后关对话，任务页仍显示"尚无委托"；与赛琳娜买情报后顶栏金币不动。

**修复**（根治而非逐处补）：
1. `engine.dispatch` 出口统一兜底：整个 switch 包在 `try` 里，`finally` 调 `sync()`。`sync()` 对 `core.S === null` 已安全（`resetWorld` 后不会崩）。
2. `sync()` 内部对落盘做 100ms 尾节流（`save` 合并、`emitChanged` 立即），避免一次命令链 N 次全量 `JSON.stringify`。
3. 异步回调（`check` 的 `scheduler.after`、战斗 `endPhase`、叙事异步流）**不走 dispatch**，各自保持显式 `sync()`，并补测这些路径。

**验收**：新增用例——在各条无同步路径上调用后断言 `bus` 收到过 `changed`（订阅计数 > 0）。手动：接任务后立即切任务页必须可见；买情报后顶栏金币立即变化。

### F-14 · 意图通道降级链断裂 + 自由行动无并发锁（P1）

### F-15 · 地下城 HUD 遮挡移动端标签栏（P1）

### F-20 · SQLite 写失败静默 + 队列不取快照（P1）

### F-44 · 端点未回 CORS 头时，四通道的失败全都长得一样（P2）

**位置**：`src/ai/openaiCompat.ts`（`failOnce` / `testConnection`）；`vite.config.ts`（`server.proxy`）。

**机制**（实机复现）：端点指向一个不回 `Access-Control-Allow-Origin` 的中转站时，浏览器把**整个响应**丢掉——`fetch` 抛 `TypeError: Failed to fetch`，连 401 / 403 都拿不到。同一个 token 的真实状态在 Node 侧（不经 CORS）才看得见：`/v1/models` 200（可见 13 个模型），`/chat/completions` 打 `gemini-3.6-flash` 得 **403 权限不足**，打 `gemini-2.5-flash` 得 **503 上游不可连**——13 个可见模型无一可通。于是同一句「Failed to fetch」同时盖住了三件要分别处置的事：Key 无效 / 令牌无权限 / 上游挂了；面板与「叙事编织诊断」也只能一起显示「调用失败 / 超时 / 返回空（保留规则原文）」。

**修复**：
1. 失败原因翻成人话再上屏：`HTTP 401 → 鉴权失败`、`HTTP 403 → 权限不足（令牌无该模型或该分组的访问权）`、`AbortError → 调用超时（N ms 内没有拿到响应）`、网络层 → `浏览器未拿到响应（端点未开放 CORS 居多，其次网络 / 域名不可达）`；toast 与运行日志共用同一句。
2. `gateway.test()` 的失败分支把原因带回去，面板不再只显示「✗ 测试失败：无响应」。
3. 降级 toast 的节流键改为「模型 + 原因」：换原因就是换要处置的事，不该被前一条压住。
4. `vite.config.ts` 增可选同源转发：设置 `TQ_LLM_PROXY=<endpoint>` 后 `npm run dev`，端点填 `http://127.0.0.1:5273/__llm/v1`——跨域请求变同源，真实状态码原样回到面板。未设置该变量时**一条规则都不注册**。

**验收**：`openaiCompat.test.ts` 增「失败诊断」五例（网络层 / 403 / 401 / 超时 / 连通性测试带原因）。代理路径实测：浏览器经 `/__llm/v1/chat/completions` 拿到 `403 权限不足`，同一模型直连只得 `Failed to fetch`。
