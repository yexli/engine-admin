## 一、这个人物的核心

**帝国里升得最快的人，手里攥着三样东西。**

- 他知道皇帝的秘密——屠村那件事，知道，但从没用过（档案：弱点与把柄）
- 他手里有政敌的把柄——赛瑞斯被撕走的那一页档案（档案 002：疑在凯尔手里）
- 他正拿贵族院的联姻网去换军方的支持——杜克压着没递的退役折子（档案 004）

所以聊他一个人，能挖出半个帝国的政治地图。**这就是"扎实"的含义：不是他话多，是他站在网中间。**

## 二、八个话题（人类可读版）

### 1. 皇权与殿权（生人可问）

| | |
|---|---|
| 表层 | 「皇权法案，为的是帝国政令出得了圣辉城。至于殿权——那是五位大人在替神明操心，我不好说什么。」 |
| 内层 | 「塞尔大人推殿权法推了两年。我拦过一次，没拦死——拦得太早，他反倒省了力气。」 |
| 深水 | 「说给你听也无妨：我要的不是皇帝赢。是陛下赢完之后，话得从这间屋子里过一遍。」 |
| 他手里的事实 | 陛下在密查各派系与神殿往来的档案；赛瑞斯在推殿权法三读；他与赛瑞斯是宿敌；**法案的真正受益者是他自己** |
| 边界 | 绝不承认受益者是自己；被追问就反问「你这话，是替谁问的」 |
| 追问钩子 | 那殿下卡你，你打算怎么办？／陛下知道你在忙这些吗？ |
| 门槛产出 | 好感 45 → 记得「凯尔谈皇权法案时留了半句没说」 |

### 2. 军机处的动向（生人可问）

| | |
|---|---|
| 表层 | 「军机处最近在算兵力账。算这个的人，通常不是要打仗，是要分钱。」 |
| 内层 | 「杜克大人递了退役折子——压在袖子里三个月了。他知道一递上去，边境就没人接。」 |
| 深水 | 「我劝过他留任。他没答应，也没拒绝。老将军这辈子只站军阵，不站人。」 |
| 他手里的事实 | 军机处首席是杜克（边防军总帅）；杜克右手三指废；退役折子没递；凯尔与杜克是盟友，正要这条军方的通路 |
| 边界 | 不承认自己在拉拢军方；被问「你想拉他站队」就反问「你说这话，是想让谁听见」 |
| 追问钩子 | 杜克会站哪边？／你们拿什么换他？ |

### 3. 眉间那道疤（生人可问）

| | |
|---|---|
| 表层 | 「（他抬手碰了碰眉间）比试留下的。贵族院的剑，比宫里的话干净多了。」 |
| 内层 | 「（他笑了一下）你不信？也难怪。」 |
| 深水 | 「那次不是比试。有人想在我还只是个侍从的时候，让我别站错队。……我没听。」 |
| 他手里的事实 | 贵族院比试三届魁首；十四岁入宫为伴读；靠三段棋局与一次「提前站队」赢得皇帝信任 |
| 边界 | 生人面前一律推到比试上 |
| 追问钩子 | 谁干的？／你后来怎么回的他？ |

> 一个小钩子的价值：他一开口就有画面，而"我没听"三个字，把他二十年的性格说完了。

### 4. 贵族院的联姻（处熟才谈）

| | |
|---|---|
| 表层 | 「贵族院的规矩，婚姻是账目。我替七家订过亲——他们签字的时候都很客气。」 |
| 内层 | 「你问我自己的那桩？……谈成了，西边的盐路并进来；谈不成，我就得另找一笔钱。」 |
| 深水 | 「（他把话岔开，笑意一点没变）比起我的婚事，你更该关心杜克大人的折子。那才是往后三年的事。」 |
| 他手里的事实 | 联姻网是他的长处；财政靠联姻维持，另有一笔黑账；他要编的是贵族院—军方—商邦三条通路 |
| 边界 | 一到自己那桩婚事就往别处引——**这个话题最深处的应答就是一次转移，没有坦白版** |

### 5. 祖父的旧怀表（处熟才谈）

| | |
|---|---|
| 表层 | 「（他低头看了一眼）老人家留下的。走得不太准，我用惯了。」 |
| 内层 | 「他没看到我入宫的第二年。……表是他这辈子唯一留给我的东西。」 |
| 深水 | 「（他把表放在桌上，没有推过来）我父亲那辈人觉得当官是荣耀。我只想让自己别再看人脸色。」 |
| 他手里的事实 | 持有物：祖父的旧怀表，他唯一的软肋物品；平民勋爵之子，十四岁入宫；表从不离身 |
| 边界 | 平日绝口不提；**把表放在桌上但不推过来，就是他给出的最大诚意** |

> 这块表，是他这个人物的"活口"。前面全是棋手，到这里才第一次露出别的成分。

### 6. 维克这个人（处熟才谈 · 交叉）

| | |
|---|---|
| 表层 | 「维克？贵族院里最周到的人。见谁都笑，谁的事都记得。」 |
| 内层 | 「他跟我做过几笔买卖。他卖消息，我买——但我从不多买。那种人，你买得越多，欠得越多。」 |
| 深水 | 「他最近跟神殿那边也熟。这个我知道。……暂时还用得上他。」 |
| 他手里的事实 | 维克是贵族院暗面、脚踏两派；十年前与暗影议会做生意，三年前搭上魔界特使；凯尔与他是盟友 |
| 边界 | **开口先替维克遮一句**；被逼到「他也在跟神殿做生意吧」才会点头 |

### 7. 皇帝不肯说的那件事（处熟才谈 · 深水要门槛）

| | |
|---|---|
| 表层 | 「（他停了一下，把茶盏放回原处）你这话，是从哪儿听来的？……这种事，我劝你别再问了。」 |
| 内层 | 「陛下信我。这份信比什么都重。你要问的那些，说出来对谁都没好处——包括你自己。」 |
| 深水 | 「（他把茶盏轻轻放下，笑意一点没变）这件事我不会说。你也别再问第二遍。」 |
| 他手里的事实 | 陛下年轻时在边境平叛中下过屠村的令；凯尔知道却从未要挟——留着比用掉值钱；这正是陛下最不确定的事 |
| 边界 | 绝不承认；越接近这件事，礼数越足、话越少 |
| 门槛产出 | 好感 70 + 亲密度 1 → **产出是一个拒绝**：确认他握着这件事，但一个字都撬不出来 |

> **这一条是整份样本里最重要的设计。** 深水区的奖励不是"他说了"，而是"你确定他知道"——
> 然后你只能去皇帝那边另找突破口。秘密还在原地，戏还在往下走。

### 8. 赛瑞斯的那页档案（深水区 · 好感 70 才出现）

| | |
|---|---|
| 表层 | 「（他笑了笑）塞尔大人年轻时心软过一回。这种小事，神殿自己都不提。」 |
| 内层 | 「那页纸在谁手里，我不清楚。……但你问对了人。」 |
| 深水 | 「留着。用掉的把柄只值一次，留着的能用十年。」 |
| 他手里的事实 | 赛瑞斯早年放走过一名受冤的叛教骑士；那份档案被撕走一页，赛瑞斯疑在凯尔手里；赛瑞斯正在推殿权法——这时机把柄最值钱 |
| 边界 | 只认「听说过」，不认「持有」；被直接问就答「你猜」 |

## 三、三层对话演示

**① 初识（冷淡档）**——你点「皇权与殿权」

> 凯尔：「皇权法案，为的是帝国政令出得了圣辉城。至于殿权——那是五位大人在替神明操心，我不好说什么。」
> 凯尔：（停顿）「这话，你是替谁问的？」

**② 处熟（友好档）**——你追问「那殿下卡你，你打算怎么办」

> 凯尔：「塞尔大人推殿权法推了两年。我拦过一次，没拦死——拦得太早，他反倒省了力气。」
> 凯尔：（他给你续了茶）「说给你听也无妨：我要的不是皇帝赢。是陛下赢完之后，话得从这间屋子里过一遍。」

**③ 交心（深水档）**——你问「皇帝不肯说的那件事」

> 凯尔：「（他把茶盏放回原处，动作很轻）你这话，是从哪儿听来的？」
> 凯尔：「陛下信我。这份信比什么都重。你要问的那些，说出来对谁都没好处——包括你自己。」
> 凯尔：「这件事我不会说。你也别再问第二遍。」
> （他起身整了整衣袖，笑意一点没变）

然后你带着这句话去皇宫找**赫尔曼**。他的档案里写着：「凯尔知晓此密，但从未以此要挟，**这正是赫尔曼最不确定的一件事**」——你从他那儿听到的是忌惮，不是秘密。

**两个人，一件事，两个方向，谁都没摊牌，而你什么都明白了。**

## 五、这张网（交叉引用）

```
                    赫尔曼（皇帝）
                  屠村 ▸ 凯尔知道却不用的那把刀
                        ▲
                        │ 最不确定的一件事
                        │
   赛瑞斯（政敌）──── 凯尔 ──── 杜克（要拉的军方）
   被撕走的一页 ◂────┤        退役折子
                        │
                    维克（盟友）
                   两头做生意，还用得上
```

玩家从这四个人中任何一个嘴里，都能听到凯尔的另一面。**这张网是 AI 即兴写不出来的东西**——它是结构的产物。

## 六、接进游戏要动什么（三步）

| 步 | 改动 | 量级 |

| 1 | `Chat.chatChips`：把话题列表换成"未谈过的标签 + 刚谈过话题的追问钩子" | 约 20 行 |

## 七、两件要你拍板的事

**1. 凯尔与皇帝的「亲族」边。** 关系数据里写着 `kael → herman: kin`，而且 `npcArchive.test.ts` 第 185 行把它锁成了断言（「凯尔与皇帝之间应有『亲族』边」）。但档案文字里，凯尔是**平民勋爵之子**、十四岁入宫当伴读。

这两种说法要么一个是另一个的伏笔（比如他有皇室血脉），要么是数据沿用了旧的宽泛用法。**我没有猜**，所以这份样本里避开了"你和陛下是什么关系"这类话题。你定了原意，我再补上这条——它很可能是我手里最好用的一张牌。

**2. 这个规格对不对。** 八条话题、三层、带交叉，一个人约 1800 字。你觉得够扎实，我就照这个标准写第一梯队 20 人；觉得哪里多余或者不够，现在改最便宜。
