# 运行拓扑与宿主说明

> 本仓库现在有三个"宿主"脚本。它们各自角色不同、端口不同、面向的读者也不同。
> 本文是唯一的权威说明（2026-10-06，随外置引擎迁移终局更新）。

---

## 总览

```text
                      ┌──────────────────────────────┐
                      │  game-host（游戏会话宿主）        │
  Tianqiong 客户端 ────│  8797 · npm run host:game      │
  （npm run dev）      │  dispatch + 24 系统 + 规则推演    │
  命令整投/快照回灌/SSE  │  [+ world-gateway 内嵌可选]      │
                      │  存档 .world-data/game-session  │
                      └──────────────────────────────┘
                      ┌──────────────────────────────┐
  admin-web ──────────│  world-host（世界观测面）          │
  （世界列表/事件/关系）  │  8798 · npm run host:world     │
                      │  天穹世界书静态种子（63 地点/15 NPC）│
                      └──────────────────────────────┘
                      ┌──────────────────────────────┐
  （文档示例）           │  http-host（G1 参考实现 PoC）     │
                      │  8798 · npm run host:http       │
                      └──────────────────────────────┘
```

## 1. game-host —— 游戏会话宿主（**游戏运行的必需进程**）

- 入口：`server/game-host.ts`（构建：`npm run build:game` → `.server-build/game-host.mjs`）
- 职责：宿主**完整裁定栈**（dispatch + 24 系统 + 规则推演兜底），客户端的全部
  GameCommand 在此裁定；事实流（SSE `/game/events/stream`）与状态快照
  （`/game/state`）回灌客户端。
- AI：三档优先级——gateway 档（`TIANQIONG_GAME_GATEWAY` 外联 / `_EMBED=1`
  内嵌 world-gateway，钥匙经 `apiKeyRef:{env}` 网关侧持握）> 客户端转发档
  > ruleSim 兜底。编织不在服务端（§30 归客户端表现层）。
- 存档：`TIANQIONG_GAME_SAVE`（缺省 `.world-data/game-session.json`），重启接续。
- 端点：`/game/health` `/game/state` `/game/new` `/game/command`
  `/game/events(+/stream)` `/game/ai-config`（+ TESTHOOK 钩子）。
- **GM 兼容面**：`/v1/worlds` 协议子集（世界列表 / `tianqiong-live` 信息 / 状态 /
  推进时间 / 事件）——管理后台把 `/world-api` 指向 **8797** 即可看到**实时对局**：
  后台推进时间走的是与玩家 wait 同一条时钟，事实经 SSE 实时推给游戏端
  （顶栏/场景/日结算全部跟进）。注意与 8798 的种子世界区分：
  **8797 = 实时对局（GM 可操作），8798 = 静态种子（仅观测）**。

## 2. world-host —— 世界观测面（管理后台用，游戏不依赖）

- 入口：`scripts/world-host.mjs`
- 职责：把天穹**世界书静态种子**（63 地点 / 15 NPC / 关系网）装配成
  world-engine 常驻世界并开 REST+SSE 服务——供 admin-web 与任意
  World Engine 客户端观测（世界列表/状态/关系/事件）。**不承载游戏裁定**。
- 存档：`.world-data/tianqiong-main.json`；可选 API Key（`TIANQIONG_WORLD_KEY`）。
- 典型用途：`VITE_WORLD_API_URL=http://127.0.0.1:8798` 起 admin-web 看天穹世界。

## 3. http-host —— G1 参考实现 PoC（文档示例，保留）

- 入口：`scripts/http-host.mjs`（SDK-GUIDE 引用的最小接入示例）。
- 与 world-host 同源同端口段，但无持久化、无鉴权——仅作"30 行接入"的参考实现保留。
- **新代码请勿依赖它**；观测面用 world-host，游戏用 game-host。

## 常见问题

**Q：只想起游戏？** `npm run host:game` + `npm run dev`，两步。
**Q：管理后台想看世界？** 再起 `npm run host:world`，admin-web 的
`VITE_WORLD_API_URL` 指向 8798。
**Q：断线了怎么办？** 停摆语义：客户端命令拒收（toast）、自动重连；
宿主重启后客户端自动回局（快照回灌）。
